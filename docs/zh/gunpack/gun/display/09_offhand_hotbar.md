# 副手与快捷栏

本页介绍枪械在副手和快捷栏中的显示位置、旋转和缩放配置。

## 副手显示 `offhand_show`

**可选**，对象类型。控制枪械在副手（左手）持握时的模型变换。

| 键         | 类型    | 说明                                    |
|-----------|-------|---------------------------------------|
| `pos`     | 数组    | 位置偏移 `[x, y, z]`                      |
| `rotate`  | 数组    | 旋转角度 `[x, y, z]`（度）                   |
| `scale`   | 数组    | 缩放比例 `[x, y, z]`，默认 `[0.6, 0.6, 0.6]` |

```json
"offhand_show": {
  "pos": [3, 20, 3.5],
  "rotate": [0, 0, 60],
  "scale": [0.5, 0.5, 0.5]
}
```

此例来自默认枪包 `ak47_display.json`。

不同枪型的副手位置差异较大，例如手枪（deagle）需要更贴近身体中心：

```json
// deagle_display.json
"offhand_show": {
  "pos": [4, 13, -2],
  "rotate": [-90, -35, 90],
  "scale": [0.5, 0.5, 0.5]
}
```

## 快捷栏显示 `hotbar_show`

**可选**，对象类型。控制枪械在快捷栏中的模型变换。不填则不显示快捷栏枪械。

一级键为快捷栏槽位索引（`"0"` 到 `"8"`），每个槽位包含与 `offhand_show` 相同结构的变换配置。未指定的槽位不渲染。

```json
"hotbar_show": {
  "0": {
    "pos": [-3, 20, 3],
    "rotate": [-180, 0, 120],
    "scale": [0.5, 0.5, 0.5]
  }
}
```

此例来自默认枪包 `ak47_display.json`。快捷栏共 9 个槽位（0~8），除去主手后最多显示 8 个。玩家通常将枪械放在 `0`、`1` 这两个快捷栏位置以便记忆，因此一般只需准备 0 号槽位的模型变换即可，其他槽位按需配置。
