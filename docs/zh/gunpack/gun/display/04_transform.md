# 视角与变换

本页介绍模型在各视角下的缩放、机瞄倍率和 FOV 配置。

## 模型缩放 `transform.scale`

**可选**，对象类型。调整模型在三种展示情景下的缩放比例。为 `[x, y, z]` 三元数组。旋转和位移使用模型内的定位组控制，此处仅缩放。

| 键             | 说明                         |
|---------------|----------------------------|
| `thirdperson` | 第三人称视角下手持枪械的缩放             |
| `ground`      | 掉落在地面的实体缩放                 |
| `fixed`       | 物品展示框内的缩放                  |

```json
"transform": {
  "scale": {
    "thirdperson": [0.6, 0.6, 0.6],
    "ground": [0.6, 0.6, 0.6],
    "fixed": [1.2, 1.2, 1.2]
  }
}
```

此例来自默认枪包 `ak47_display.json`。

`transform` 整体为可选，内部三个子键也各自可选——未指定的保持原始缩放。

## 机瞄放大倍数 `iron_zoom`

**可选**，数值类型。使用无瞄具配件或机瞄时的放大倍数。默认 `1.2`。

```json
"iron_zoom": 1.33
```

此例来自默认枪包 `ak47_display.json`。该值越大，机瞄时视野越近。

## 常驻 FOV `model_fov` <Badge text="内测版功能" type="warning" />

**可选**，数值类型。常驻持枪状态下手部模型的视场角（FOV）。调整此值影响腰射时的视觉范围。

```json
"model_fov": 60
```

## 开镜 FOV `zoom_model_fov`

**可选**，数值类型。开镜瞄准时手部模型的视场角。此值通常小于 `model_fov`，产生放大/拉近效果。

```json
"zoom_model_fov": 45
```

::: tip
`zoom_model_fov` 仅影响手部模型的渲染 FOV，不改变世界视野。实际的视野缩放由瞄具配件的倍率属性控制。
:::
