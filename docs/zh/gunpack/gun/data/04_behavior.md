# 枪械行为

本页介绍枪栓类型、拉栓上膛时长、趴下/斜握行为以及瞄准退出控制的配置。

## 枪栓类型 `bolt`

**必填**，枚举类型。决定枪械的枪栓工作方式，会影响枪械模型中特定分组的显示控制。

| 值               | 说明                                                     |
|-----------------|--------------------------------------------------------|
| `closed_bolt`   | 闭膛待击。例如最后一发子弹打完后会隐藏模型中 `bullet_in_barrel` 分组，子弹上膛后恢复显示 |
| `open_bolt`     | 开膛待机。例如模型中 `bullet_in_barrel` 分组始终隐藏                   |
| `manual_action` | 手动上膛，每次射击后需要手动拉栓才能继续开火                                 |

```json
"bolt": "closed_bolt"
```

## 拉栓上膛时长 `bolt_action_time`

**可选**，数值类型。仅当 `bolt` 为 `manual_action` 时有效，单位为秒。指定每次射击后拉栓动作的时长。

```json
"bolt_action_time": 0.9
```

## 趴下 `can_crawl`

**可选**，布尔值。是否允许持枪时趴下，默认 `true`。

```json
"can_crawl": true
```

## 斜握 `can_slide`

**可选**，布尔值。是否允许斜握（仅视觉效果），默认 `true`。

```json
"can_slide": true
```

::: tip
斜握在玩家潜行（蹲下）时触发，仅改变持枪姿态的视觉表现，不影响任何数值。
:::

## 换弹退出瞄准 `force_aim_exit_on_reload` <Badge text="内测版功能" type="warning" />

**可选**，布尔值。是否在换弹时强制退出瞄准（开镜）状态，默认 `false`。

```json
"force_aim_exit_on_reload": true
```

| 值       | 说明                                        |
|---------|-------------------------------------------|
| `true`  | 换弹开始时立即退出瞄准，且**换弹期间禁止重新开镜**（持续 tick 检测阻止） |
| `false` | 换弹时保持当前瞄准状态不变                             |

典型用途：机枪（M249、PKM）、掰管霰弹枪（DB Long/Short）、左轮手枪（Taurus 500/943、Rhino 357）。这些枪械的换弹动画在瞄准（ADS）视角下会发生穿模或视觉异常，因此需要强制退出。

## 拉栓退出瞄准 `force_aim_exit_on_bolt` <Badge text="内测版功能" type="warning" />

**可选**，布尔值。是否在拉栓时强制退出瞄准状态，默认 `false`。

```json
"force_aim_exit_on_bolt": true
```

| 值       | 说明                                        |
|---------|-------------------------------------------|
| `true`  | 拉栓开始时立即退出瞄准，且**拉栓期间禁止重新开镜**（持续 tick 检测阻止） |
| `false` | 拉栓时保持当前瞄准状态不变                             |

> 另请参见：[display - 动画与状态机](../display/02_animation) —— `bolt` 枪栓类型影响动画状态机的行为，特殊枪栓类型通常需要自定义状态机脚本。

## 卸弹 `allow_ammo_unload` <Badge text="内测版功能" type="warning" />

**可选**，布尔值。是否允许玩家用**卸弹键**（默认 `Alt + R`，可在按键设置中修改）主动卸出枪内弹药，默认 `false`。

卸出的弹药会作为物品返回背包。开膛待击的枪械不卸膛内一发；虚拟备弹按虚拟备弹规则返还。

```json
"allow_ammo_unload": true
```

**实际能否卸弹**还受以下条件约束，任一不满足则提示"该武器不支持快速卸载弹药"或"当前不能卸载"：

| 条件 | 说明 |
|-----|------|
| 换弹配置不是无限弹药 | `reload` 为 `infinite` 的枪械无法卸弹 |
| 换弹类型不是 `fuel` / `inventory` | 燃料武器、背包直读武器无法卸弹 |
| 处于空闲状态 | 换弹、拉栓、射击冷却、掏枪冷却、近战冷却、冲刺、瞄准、蓄力期间均不可卸弹 |

::: tip 有脚本的枪械需要额外声明
**没有配置 `script` 的枪械不受本字段限制**，默认可卸弹。一旦配置了 `script`，则需要满足**其一**：

- 显式写 `"allow_ammo_unload": true`；
- 脚本中定义了 `unload_ammo` 全局函数（脚本自行接管卸弹结算）。

否则该枪械会被判定为不支持卸弹。
:::

::: tip 脚本控制的逐发卸弹
需要按数量精确卸弹（例如泵动霰弹枪逐发退出）时，逻辑脚本可以调用 `unloadAmmo(barrel, amount)`：

- `barrel`：`0` 保留膛内一发，`1` 一并卸出膛内一发；
- `amount`：弹匣卸出数量，`0` 保留弹匣，`-1` 清空弹匣。

该调用仅在服务端结算，且不会再次触发 `unload_ammo` 回调，脚本需自行控制调用时机与次数。
:::

> - 卸弹成功时播放 `sounds.unload`，详见[音效 - 音效字段](../display/08_sounds.md#音效字段-sounds)。
> - 目前**没有专门的卸弹动画**。触发卸弹时会向状态机发送 `inspect_break_out` 输入（与"中断检视"共用），仅用于打断正在进行的检视动作。
