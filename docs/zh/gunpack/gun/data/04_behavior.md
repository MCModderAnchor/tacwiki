# 枪械行为

本页介绍枪栓类型、拉栓上膛时长、趴下/斜握行为以及瞄准退出控制的配置。

## 枪栓类型 `bolt`

**必填**，枚举类型。决定枪械的枪栓工作方式，会影响枪械模型中特定分组的显示控制。

| 值               | 说明                                                     |
|-----------------|--------------------------------------------------------|
| `closed_bolt`   | 闭膛待击。例如最后一发子弹打完后会隐藏模型中 `bullet_in_barrel` 分组，子弹上膛后恢复显示 |
| `open_bolt`     | 开膛待机。例如模型中 `bullet_in_barrel` 分组始终隐藏                   |
| `manual_action` | 手动上膛，每次射击后需要手动拉栓才能继续开火                                 |

```json
"bolt": "closed_bolt"
```

## 拉栓上膛时长 `bolt_action_time`

**可选**，数值类型。仅当 `bolt` 为 `manual_action` 时有效，单位为秒。指定每次射击后拉栓动作的时长。

```json
"bolt_action_time": 0.9
```

## 趴下 `can_crawl`

**可选**，布尔值。是否允许持枪时趴下，默认 `true`。

```json
"can_crawl": true
```

## 斜握 `can_slide`

**可选**，布尔值。是否允许斜握（仅视觉效果），默认 `true`。

```json
"can_slide": true
```

::: tip
斜握在玩家潜行（蹲下）时触发，仅改变持枪姿态的视觉表现，不影响任何数值。
:::

## 换弹退出瞄准 `force_aim_exit_on_reload`

**可选**，布尔值。是否在换弹时强制退出瞄准（开镜）状态，默认 `false`。

```json
"force_aim_exit_on_reload": true
```

| 值       | 说明                                        |
|---------|-------------------------------------------|
| `true`  | 换弹开始时立即退出瞄准，且**换弹期间禁止重新开镜**（持续 tick 检测阻止） |
| `false` | 换弹时保持当前瞄准状态不变                             |

典型用途：机枪（M249、PKM）、掰管霰弹枪（DB Long/Short）、左轮手枪（Taurus 500/943、Rhino 357）。这些枪械的换弹动画在瞄准（ADS）视角下会发生穿模或视觉异常，因此需要强制退出。

## 拉栓退出瞄准 `force_aim_exit_on_bolt`

**可选**，布尔值。是否在拉栓时强制退出瞄准状态，默认 `false`。

```json
"force_aim_exit_on_bolt": true
```

| 值       | 说明                                        |
|---------|-------------------------------------------|
| `true`  | 拉栓开始时立即退出瞄准，且**拉栓期间禁止重新开镜**（持续 tick 检测阻止） |
| `false` | 拉栓时保持当前瞄准状态不变                             |

> 另请参见：[display - 动画与状态机](../display/02_animation) —— `bolt` 枪栓类型影响动画状态机的行为，特殊枪栓类型通常需要自定义状态机脚本。
